# सखी महिला बचत गट (Sakhi Bachat Gat Management System)

A multi-edition Self-Help Group (SHG) financial accounting and loan management system built with Flutter and Supabase.

## Available Editions
- **Windows**: Offline, Hybrid, Online (.exe)
- **Android**: Offline, Hybrid, Online (.apk)
- **macOS & iOS**: Automated CI/CD builds via GitHub Actions (.zip / .ipa)

## Automated CI/CD Builds
- **macOS Desktop App**: Automatically compiled and zipped on macOS runner.
- **iOS IPA**: Automatically compiled and packaged into installable `.ipa` format.
